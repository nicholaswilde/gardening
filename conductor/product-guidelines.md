# Product Guidelines

## Prose & Writing Style

- **Tone**: Friendly, clear, and informative. It should read like a personal journal entry mixed with technical documentation.
- **Formatting**: Use bold text for key dates and metrics. Use list format for care instructions.
- **Naming Conventions**: Plant pages should follow kebab-case naming (e.g., `sungold-tomato.md` or `cilantro-2025.md` for historical ones).
- **Emojis**: Use standard gardening/plant emojis (e.g., `:seedling:`, `:tomato:`, `:book:`, `:sun_with_face:`, `:droplet:`) to add visual interest to page headers.

## Documentation Structure

- **Beds**: Document soil type, location (sun exposure), and active plants.
- **Plants**: Document variety, date planted, source (seeds/starts), watering schedule, harvest notes, and current status.
- **Reference**: Keep care guides up to date and reference them directly in plant pages.

## Image & Media Guidelines

- All images must be stored in `docs/assets/images/` and optimized using the `scripts/optimize-images.sh` script to keep site sizes manageable.
- Alt tags must be descriptive and follow the format: `[Plant/Bed Name] - [Detail/Stage of Growth] - [YYYY-MM-DD]`.
