# Gardening History & Documentation Tracker

## Product Vision
A personalized, high-performance static site and documentation system that tracks and archives personal gardening history, including plant growth, bed mapping, container utilization, and infrastructure status. It serves as a digital garden journal and reference point for future seasons.

## Core Features
1. **Plant Tracking**: Individual pages documenting each plant's lifecycle, care notes, dates, and status (e.g., active or archived).
2. **Infrastructure Mapping**: Detailed documentation of raised beds, containers (pots), and irrigation systems.
3. **Seasonal Archives**: Historical records of plants grown in past years (e.g., 2025) to compare performance and yield.
4. **Interactive Reference Guides**: Style guides, care references, and future planning documents.
5. **Static Site Dashboard**: Automatically built static website generated from Markdown files for convenient browsing.

## Target Audience
- **Nicholas Wilde** (the primary gardener and developer) to track active and historic garden components.
- Other gardening enthusiasts interested in reviewing experimental setups, irrigation configurations, or planting schedules.

## Out of Scope
- E-commerce or commerce integration (selling seeds or produce).
- Real-time IoT sensor telemetry database (only static documentation/reference is stored).
- Multiple user authentication or multi-tenant hosting.
