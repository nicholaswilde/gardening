# Style Guide Enforcement

Whenever you are instructed to create, edit, or refactor any markdown page (`.md`) or Jinja template (`.md.j2`) in this repository, you must execute the following protocol:

1. Read the contents of `docs/reference/style-guide.md`.
2. Strictly apply the emoji shortcodes for all H1 and H2 headings as defined in the guide.
3. Strictly apply the Material Design icon shortcodes (`:material-...:`) for all metadata, fields, and admonition blocks as defined in the guide.
4. Do not invent new icons or substitute formatting without explicit permission.
